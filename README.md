# aliux-ds

A shadcn/ui-derived Figma component library, built entirely via standalone
scripts pasted into Figma's developer console (no plugin manifest, no
packaging).

- `figma-scripts/` — one self-invoking async script per phase/component,
  pasteable as-is into Figma's console.
- `PROGRESS.md` — running status: variable foundation, completed/remaining
  components, flagged issues awaiting approval.

See `PROGRESS.md` for current status before running any script.
